# Iris-Dataset-Analysis-in-Python
The Iris dataset is one of the most famous datasets used in  data analysis and machine learning. It contains 150  observations of iris flowers from three species: Iris-setosa,  Irisversicolor, and Iris-virginica, with measurements of sepal  length, sepal width, petal length, and petal width.
The Exploratory Data Analysis (EDA) and Model development is carried out using Python programming language.
